03 / WHAT SURPRISED ME

The answer is not already waiting.

One of the most surprising things I discovered is how language models generate text.

A SMALL DETAIL. A BIG IDEA.
01 → ∞

One piece at a time.

Many language models generate responses token by token. Each new token is selected using the model's learned patterns and the context available so far.

The response is built as it unfolds. It is not simply a complete paragraph retrieved from a hidden library.
